# Склад с молотка
Русскоязычная игра по мотивам аукционов складов для 3–7 человек. Нужен Python 3.8+ на одном компьютере. На телефонах достаточно браузера.

Из корня репозитория запустите на Windows `py auction/server.py`, на macOS или Linux — `python3 auction/server.py`. С телефона в общей сети Wi-Fi откройте напечатанный адрес компьютера с портом 8080. Если адрес не подходит, посмотрите IPv4 Wi-Fi в настройках сети компьютера. На Windows разрешите Python входящие подключения в частной сети.

Создайте комнату и передайте ссылку или код друзьям. Для восстановления места после обновления используйте ту же вкладку. Сервер хранит комнаты в памяти до остановки. Интернет, внешний сервис комнат и установка пакетов не нужны. Правила доступны на игровом экране.
